# my-cli Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Node.js + TypeScript CLI framework with auto-registered commands, interactive prompts, styled output, and config management.

**Architecture:** Commander handles command routing. Commands live in `src/commands/` as individual files exporting a `Command` object. `cli.ts` auto-scans and registers them. Utility modules (logger, prompt, config) provide shared capabilities.

**Tech Stack:** Node.js 22+, TypeScript, commander, inquirer, chalk, ora

### Task 5: Create config utility

**Files:**
- Create: `src/utils/config.ts`

- [ ] **Step 1: Create src/utils/config.ts**

```ts
import { readFileSync, writeFileSync, existsSync } from 'node:fs';
import { join } from 'node:path';
import { homedir } from 'node:os';

const CONFIG_PATH = join(homedir(), '.my-clirc.json');

const defaults: Record<string, string> = {
  locale: 'zh-CN',
  theme: 'default',
};

function readConfig(): Record<string, string> {
  if (!existsSync(CONFIG_PATH)) return { ...defaults };
  try {
    const raw = readFileSync(CONFIG_PATH, 'utf-8');
    return { ...defaults, ...JSON.parse(raw) };
  } catch {
    return { ...defaults };
  }
}

export const config = {
  get: (key: string): string | undefined => {
    return readConfig()[key];
  },

  set: (key: string, value: string): void => {
    const current = readConfig();
    current[key] = value;
    writeFileSync(CONFIG_PATH, JSON.stringify(current, null, 2) + '\n', 'utf-8');
  },

  list: (): Record<string, string> => {
    return readConfig();
  },
};
```

### Task 7: Create config command

**Files:**
- Create: `src/commands/config-cmd.ts`

- [ ] **Step 1: Create src/commands/config-cmd.ts**

The config command has sub-actions (list / get / set). It reads positional args to determine which sub-action to run.

```ts
import type { Command } from '../types.js';
import { config } from '../utils/config.js';
import { logger } from '../utils/logger.js';

export default {
  name: 'config',
  description: 'Manage CLI configuration',
  arguments: '<action> [key] [value]',
  options: [],
  action: async (args, _opts) => {
    const action = args.positional[0] as string;
    const key = args.positional[1] as string | undefined;
    const value = args.positional[2] as string | undefined;

    switch (action) {
      case 'list': {
        const all = config.list();
        for (const [k, v] of Object.entries(all)) {
          console.log(`  ${k} = ${v}`);
        }
        break;
      }
      case 'get': {
        if (!key) {
          logger.error('Usage: my-cli config get <key>');
          process.exit(1);
        }
        const val = config.get(key);
        if (val === undefined) {
          logger.warn(`Key "${key}" not found`);
        } else {
          console.log(val);
        }
        break;
      }
      case 'set': {
        if (!key || value === undefined) {
          logger.error('Usage: my-cli config set <key> <value>');
          process.exit(1);
        }
        config.set(key, value);
        logger.success(`Set ${key} = ${value}`);
        break;
      }
      default:
        logger.error(`Unknown action "${action}". Use: list, get, set`);
        process.exit(1);
    }
  },
} satisfies Command;
```

### Task 8: Create CLI init with auto-registration

**Files:**
- Create: `src/cli.ts`

- [ ] **Step 1: Create src/cli.ts**

```ts
import { Command as CommanderCommand } from 'commander';
import type { Command } from './types.js';
import { readdirSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { dirname, join } from 'node:path';

export async function createProgram(): Promise<CommanderCommand> {
  const program = new CommanderCommand();
  program
    .name('my-cli')
    .description('A general-purpose CLI framework')
    .version('0.1.0');

  const __dirname = dirname(fileURLToPath(import.meta.url));
  const commandsDir = join(__dirname, 'commands');
  const files = readdirSync(commandsDir).filter((f) => f.endsWith('.js'));

  for (const file of files) {
    const mod = await import(join(commandsDir, file));
    const cmd: Command = mod.default;

    const c = program.command(cmd.name).description(cmd.description);
    if (cmd.arguments) {
      c.arguments(cmd.arguments);
    }
    for (const opt of cmd.options ?? []) {
      c.option(opt.flags, opt.description, opt.default);
    }
    c.action(async (...rest) => {
      const opts = rest.pop() as Record<string, unknown>;
      await cmd.action({ positional: rest }, opts);
    });
  }

  return program;
}
```
